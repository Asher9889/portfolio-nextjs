# Design

## Visual direction
Editorial portfolio with a strong featured work section, asymmetric layout, and a mix of large display type with clean sans-serif UI text.

## Color
- Base: warm off-white and near-black neutrals
- Accent: muted green and cool blue for emphasis
- Use semantic theme tokens for surface and text colors
- Avoid hard-coded pure black and pure white where possible

## Typography
- Display: Playfair Display for hero-style emphasis
- UI/body: Geist for navigation, labels, and supporting text
- Keep hierarchy strong with size and weight contrast

## Layout
- Use one dominant featured showcase area
- Pair it with a narrower support rail and concise proof points
- Favor asymmetric spacing over centered card grids

## Components
- Sticky navigation with theme toggle and booking action
- Hero with oversized headline and supporting statement
- Work showcase with large preview canvas, metrics, and supporting notes

## Theme
- Light-first presentation with a clear dark mode switch
- Dark mode should invert surface hierarchy, not just swap text color
